Sobre o TrocaTicket

O TrocaTicket é uma plataforma digital para descoberta, criação, gerenciamento, comercialização e transferência segura de ingressos. Liga participantes, organizadores e vendedores num mesmo ecossistema — da vitrine à catraca.

O que é

Tecnologia para eventos: cartaz público, bilheteria digital, QR Code, check-in, marketplace (quando liberado) e painel operacional para quem produz.

O que este site é

Uma releitura retrô (vermelho e preto, estética de bilheteria) feita para trabalho de faculdade. Não substitui o produto em trocaticket.com.br.

Stack da plataforma original (referência)

Next.js, React, TypeScript, Supabase, PostgreSQL, autenticação e Row Level Security. Esta versão acadêmica é HTML, CSS e JavaScript estáticos.
